# Скриншоты к задачам

Один кадр на задачу, только там, где есть «момент узнавания»: читатель смотрит
на экран и понимает, что у него всё как надо. Задачи без такого момента идут
без картинки. Модули 0 и 1 снимаются сейчас, модули 2 и 3 — после переделки
курса под сквозной продукт (тогда кадры с файлами проекта совпадут с текстом).

## Подготовка (один раз, до съёмки)

- Отдельный пользователь ОС или переименованная домашняя папка с нейтральным
  именем, чтобы в путях не светилось личное: `C:\Users\user`.
- Одна тема терминала на все кадры: светлая, тот же шрифт, тот же размер окна
  (примерно 100×30 символов). Claude Code тоже в светлой теме (`/config`).
- Кадр — только окно терминала, без рабочего стола и панели задач. Можно снимать
  всё окно с пустым низом: обрезка по содержимому делается скриптом
  `powershell -File scripts/crop-screenshots.ps1` (все PNG в папке, повторный
  запуск безопасен). Без обрезки текст на сайте будет нечитаемым.
- Цвета подсветки PowerShell под светлый фон, один раз в `$PROFILE`:
  `Set-PSReadLineOption -Colors @{ Command = 'DarkBlue'; Parameter = 'DarkCyan'; Default = 'Black'; Operator = 'DarkGray'; String = 'DarkGreen'; Number = 'DarkRed'; Variable = 'DarkMagenta'; Type = 'DarkGray'; Member = 'Black' }`
- Формат PNG, до 300 КБ. Имя файла: `<id задачи>-<суть>.png`,
  например `01-02-first-run.png`. Папка: `public/screenshots/`.
- Перед съёмкой очистить экран (`cls` / `clear`), чтобы в кадре была только
  команда и её вывод.
- Тёмная тема сайта: второй комплект не снимается. Терминальные кадры
  инвертируются через CSS автоматически. Если инверсия для кадра выглядит
  плохо (страница браузера), положите рядом тёмный вариант с суффиксом
  `-dark` (`00-02-github-code-dark.png`) — сайт подставит его сам. Кадры с
  графикой (маскот Claude Code в шапке сессии, octocat на GitHub) инверсия
  перекрашивает — такие помечаются в Markdown заголовком `"as-is"`:
  `![подпись](/screenshots/x.png "as-is")`, они остаются светлыми и в тёмной теме.
- Дата съёмки = `verified_date` задачи: пройдя задачу и сняв кадр, ставьте дату
  во frontmatter.

Вставка в Markdown задачи, сразу после шага, к которому относится кадр:

```markdown
![Первый запуск: приглашение к вводу](/screenshots/01-02-first-run.png)
```

Текст в квадратных скобках — подпись, она показывается под кадром.
