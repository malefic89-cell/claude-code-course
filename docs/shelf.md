# «Полка» — сквозной продукт курса

Статус: черновик на утверждение автора. Решения, которые уже приняты:
продукт задан по умолчанию, один на весь курс, HTML + CSS + JS без сборки,
публикация — отдельный короткий модуль после шестого.

## Что это

Каталог личной коллекции: книги, фильмы, игры, настолки, растения — тему
выбирает ученик в первой задаче продукта. Скелет от темы не зависит, задачи
формулируются через «карточка» и «коллекция», без привязки к книгам.

Почему именно каталог: фичи независимы друг от друга (есть что раздать
субагентам в модуле 5), содержание личное (человек будет этим пользоваться),
нет логики дат, на которой новички ломаются.

## Скелет к концу модуля 3

Одна страница `index.html` + `styles.css` + `app.js`, открывается двойным
кликом, сервер не нужен:

- список карточек: название, автор/год (одно поле «подпись»), обложка по
  ссылке или эмодзи, если ссылки нет;
- форма добавления карточки;
- поиск по названию;
- данные в `localStorage`, не пропадают при перезагрузке;
- CLAUDE.md с описанием продукта и правилами.

Всё это Claude пишет за несколько запросов. Ученик учится ставить задачу,
читать diff, откатывать и планировать — на своём продукте.

## Задача → что происходит с продуктом

Правила: id и порядок задач не меняются; правится только текст. Колонка
«правка» — объём изменения текста: **нет** / **фраза** (заменить проект или
папку) / **шаги** (переписать 1–3 шага) / **заново** (переписать задачу).
