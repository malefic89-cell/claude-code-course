# Пилот (этап 4)

Цель: 2–3 тестера разного уровня (сотрудник + ученик) проходят модули 1–3,
мы собираем точки застревания и сверяем оценки времени с фактом.

Сайт курса: https://malefic89-cell.github.io/claude-code-course/

## Инструкция для тестера

1. Откройте сайт (можно с телефона, но задачи выполняются в терминале на компьютере).
2. Проходите задачи по порядку, начиная с модуля 1. Ничего не пропускайте.
3. Отмечайте каждую выполненную задачу кнопкой «Отметить выполненной».
4. Сразу после каждой задачи заполняйте строку в таблице обратной связи —
   по горячим следам, не в конце дня.
5. Если застряли больше чем на 15 минут — запишите, где именно, и переходите
   к следующей задаче. Это самый ценный сигнал для нас, а не ваша ошибка.
6. Подсказки открывать можно и нужно — отметьте в таблице, помогли ли они.

## Таблица обратной связи

Одна строка на задачу. Колонка «минуты» — фактическое время, включая тупики.

| Задача | Минут (факт) | Застрял? Где именно | Что непонятно в тексте | Открывал подсказки? Помогли? | Идеи/замечания |
|--------|--------------|---------------------|------------------------|------------------------------|----------------|
| 01-00  |              |                     |                        |                              |                |
| 01-01  |              |                     |                        |                              |                |

…и так далее по всем задачам модулей 1–3 (см. список на сайте).

Общие вопросы в конце прохождения:

1. Насколько сложным был курс в целом (1–5) и где был пик сложности?
2. Какая задача была самой полезной? Какая — лишней?
3. Чего не хватило, чтобы начать применять Claude Code в своей работе/учёбе?
4. Удобно ли пользоваться сайтом с вашего устройства? Что мешало?

## Обработка результатов (автор курса)

- Свести таблицы тестеров, посчитать медианное время по каждой задаче.
- Задачи, где факт > 2× `estimated_minutes` или застревали ≥2 тестеров, —
  кандидаты на правку текста (сначала текст, UI — только если проблема в нём).
- По итогам: обновить `estimated_minutes` и тексты в `/content`,
  проставить `verified_date` перепроверенным задачам.
