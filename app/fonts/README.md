# Шрифты

Подмножества woff2 (latin + cyrillic) из пакетов Fontsource v5
(https://fontsource.org), лицензия SIL Open Font License 1.1:

- Playfair Display 500/700, 500 italic — заголовки
- Source Serif 4 700 (только latin) — цифры
- Source Sans 3 400/600 — текст
- IBM Plex Mono 400/500 — код и подписи

Подключены через `@font-face` в `app/globals.css`; сборке сеть не нужна.
