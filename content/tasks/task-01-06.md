## Цель

Сделать первую правку через Claude Code и понять механизм подтверждения: Claude показывает diff (от англ. difference — «разница»), то есть чем новая версия файла отличается от старой, и ждёт вашего разрешения.

## Инструкция (пошагово)

1. Работайте в «Полке» (папка `claude-lab`). Сейчас там заготовка из модуля 0: `index.html` с заголовком «Моя полка». Решите, что вы коллекционируете — книги, фильмы, игры, растения, что угодно, — и придумайте своей полке название.
2. Попросите первую правку, подставив своё:
   ```
   Сделай из index.html страницу каталога моей коллекции книг. Название полки — «Полка Ивана». Добавь одну карточку-пример: название, короткая подпись и обложка-эмодзи. Стили вынеси в styles.css. Без библиотек и без сборки — страница должна открываться двойным кликом.
   ```
3. Когда Claude предложит изменение, **не подтверждайте сразу** — прочитайте diff: зелёные строки добавляются, красные удаляются.

   ![Claude показывает diff правки и спрашивает разрешение: Yes, Yes для всей сессии, No](/screenshots/01-06-diff-prompt.png)
4. Подтвердите изменение. Claude может спросить разрешение дважды — отдельно на `index.html` и на новый `styles.css`; читайте каждый diff.
5. Откройте `index.html` двойным кликом — в браузере появится ваша полка с первой карточкой. Затем откройте файл в редакторе и найдите правку в коде.
6. Посмотрите варианты ответа на запрос разрешения: обычно можно разрешить один раз, разрешить на всю сессию или отклонить.
7. Сохраните первую версию продукта в историю — как в задаче 00-04:
   ```bash
   git add -A
   git commit -m "Полка: первая карточка"
   ```

## Критерий выполнения

Задача выполнена, если вы видели diff до подтверждения, `index.html` открывается в браузере и показывает полку с карточкой, а `git log --oneline` показывает коммит с этой правкой.

## Подсказки

- Тема коллекции и название — ваши. Дальше в задачах говорится «карточка» и «коллекция»; подставляйте своё.

- Правило курса: **сначала читать diff, потом подтверждать.** Привычка «жать да не глядя» — главный источник проблем у новичков.
- Если diff не тот, что вы хотели, — отклоните и переформулируйте запрос точнее.
