## Цель

Подключить MCP-сервер, через который Claude управляет браузером, и убедиться, что он отвечает.

## Инструкция (пошагово)

Браузерных серверов несколько: расширение Claude in Chrome от Anthropic и сторонние на базе Playwright. Курс называет их «браузер»; какой именно поставить — в подсказках, потому что этот список меняется.

1. Выберите сервер из подсказок и подключите его командой `claude mcp add …` в области проекта.
2. Запустите `claude` в «Полке» и выполните `/mcp`. Сервер должен быть в списке со статусом «подключён». Если статус другой — задача 04-06 про это, но сначала перечитайте команду добавления.
3. Дайте первую команду браузеру:
   ```
   Открой в браузере файл index.html из этого проекта и скажи, что ты видишь на странице
   ```
4. Claude попросит разрешение на действия браузера — прочитайте, что именно он собирается сделать, и разрешите.
5. Сравните ответ с тем, что вы видите сами: заголовок полки, число карточек, поле поиска.

## Критерий выполнения

Задача выполнена, если `/mcp` показывает браузерный сервер подключённым, а Claude описал вашу «Полку» так, как она выглядит в браузере.

## Подсказки

- **Claude in Chrome**: расширение для Chrome от Anthropic; после установки Claude Code видит вкладки браузера. Требует Chrome и вход в тот же аккаунт.
- **Playwright MCP**: сервер на Node.js, открывает свой браузер без расширений. Команда вида `claude mcp add playwright -- npx @playwright/mcp@latest` — проверьте актуальную в документации сервера.
- Первое обращение к браузеру медленное: сервер запускается. Второе — быстрее.
