## Цель

Подключить браузер к Claude Code через расширение Claude in Chrome и убедиться, что сервер отвечает.

## Инструкция (пошагово)

Встроенный сервер `claude-in-chrome` управляет вашим Chrome через расширение от Anthropic. Ставить сервер не нужно, нужно только расширение. Если у вас нет Chrome или расширение недоступно, в подсказках есть запасной вариант.

1. Установите расширение Claude in Chrome: адрес `claude.ai/chrome`, кнопка установки ведёт в магазин Chrome. После установки закрепите значок расширения на панели и войдите в нём в тот же аккаунт, что и в Claude Code.
2. Перезапустите Chrome и запустите `claude` в «Полке». Выполните `/mcp`: сервер `claude-in-chrome` должен быть со статусом `connected` и числом инструментов. Если статус другой — перезапустите Chrome ещё раз, расширение подключается при старте.

   ![/mcp: встроенный сервер claude-in-chrome подключён, 22 инструмента](/screenshots/04-02-mcp-connected.png)
3. Дайте первую команду браузеру:
   ```
   Открой в браузере файл index.html из этого проекта и скажи, что ты видишь на странице
   ```
4. Claude попросит разрешение на действия браузера — прочитайте, что именно он собирается сделать, и разрешите. Возможно, перед этим он попросит запустить простой локальный сервер, потому что расширение открывает страницы по адресу, а не файлы с диска; это тоже нормально.
5. Сравните ответ с тем, что вы видите сами: заголовок полки, число карточек, поле поиска.

## Критерий выполнения

Задача выполнена, если `/mcp` показывает `claude-in-chrome` подключённым, а Claude описал вашу «Полку» так, как она выглядит в браузере.

## Подсказки

- Расширение работает только в Chrome; в других браузерах на движке Chromium может не заработать.
- **Запасной вариант без расширения — Playwright MCP**: сервер на Node.js, открывает свой браузер. Подключается командой `claude mcp add playwright -- npx @playwright/mcp@latest`; актуальную команду смотрите в документации сервера. Дальше в курсе слово «браузер» относится к любому из двух.
- Первое обращение к браузеру медленное. Второе — быстрее.
