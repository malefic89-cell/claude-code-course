## Цель

Подключить второй MCP-сервер, на этот раз для файлов за пределами проекта, и запретить один его инструмент через `/permissions`.

## Инструкция (пошагово)

Второй сервер берём самый простой из существующих: файловый. Он даёт Claude читать и писать файлы в папке, которую вы укажете, даже если это не папка проекта. Ключи и аккаунты ему не нужны, а инструментов у него мало и они понятные: прочитать файл, записать файл, показать список папки.

1. Выйдите из сессии (`/exit`) и подключите сервер в области пользователя, указав папку `C:\Learning` (на macOS — путь к вашей учебной папке):
   ```bash
   claude mcp add --scope user files -- npx -y @modelcontextprotocol/server-filesystem C:\Learning
   ```
   Здесь `files` — имя, под которым сервер будет виден в списках, `--scope user` — область «для всех моих проектов», а всё после `--` — команда запуска сервера.
2. Проверьте: `claude mcp list` показывает два сервера, браузерный из 04-02 и `files`.
3. Запустите `claude` в «Полке» и выполните `/mcp`. Выберите `files` и откройте список его инструментов: там будут `read_file`, `write_file`, `list_directory` и несколько похожих. Это и есть всё, что Claude сможет делать через этот сервер.
4. Дайте задание, которое требует выхода за пределы проекта:
   ```
   Покажи список файлов в папке C:\Learning\Spoon-Knife через сервер files
   ```
   В запросе разрешения будет указан сервер и инструмент: `files` → `list_directory`. Разрешите.
5. Теперь запретите запись. Выполните `/permissions`, перейдите на вкладку запретов (Deny) и добавьте правило:
   ```
   mcp__files__write_file
   ```
   Формат правила: `mcp__<имя сервера>__<инструмент>`.

   ![/permissions, вкладка Deny: правило mcp__files__write_file добавлено](/screenshots/04-05-deny-tool.png)
6. Проверьте запрет:
   ```
   Создай через сервер files файл C:\Learning\test.txt с одной строкой
   ```
   Claude должен сообщить, что инструмент запрещён, и не создать файл. Убедитесь: `ls C:\Learning` в терминале.

## Критерий выполнения

Задача выполнена, если `claude mcp list` показывает два сервера, а попытка записать файл через `files` отклонена правилом из `/permissions`.

## Подсказки

- Сервер запускается через `npx`, то есть скачивается при первом старте: первый `/mcp` после добавления может занять минуту. Node.js у вас уже есть с задачи 01-00.
- Область `user` хранит настройку в вашем профиле, а не в проекте, поэтому в git «Полки» она не попадёт. Так и надо: доступ к папкам на вашем диске — личное дело, а не часть проекта.
- Правило безопасности: чем больше у сервера прав, тем строже разрешения. Файловому серверу дали одну папку и запретили запись; серверу с ключом от GitHub дали бы ещё меньше.
- Если сервер отвечает, что разрешена только папка проекта, хотя в команде указан `C:\Learning`: новые версии файлового сервера берут список папок от клиента, а Claude Code передаёт текущую папку. Тогда запустите `claude` из `C:\Learning`, и обе папки окажутся внутри.
- Удалить сервер, когда наиграетесь: `claude mcp remove --scope user files`. Правило в `/permissions` можно оставить — без сервера оно ничему не мешает.
