## Цель

Переложить на Claude ручную проверку из задачи 03-07: он сам открывает «Полку», вводит запрос в поиск и докладывает результат.

## Инструкция (пошагово)

1. В сессии с подключённым браузером попросите:
   ```
   Открой index.html, введи в поиск часть названия одной из карточек и скажи, сколько карточек осталось на экране
   ```
2. Наблюдайте: Claude перечисляет действия (открыть страницу, найти поле, ввести текст, прочитать список) и на каждое, где нужно, спрашивает разрешение.
3. Проверьте ответ сами в своём браузере. Совпало?
4. Усложните: попросите проверить крайние случаи из 03-07 — другой регистр, пробел в конце, пустой запрос — одним сообщением.
5. Попросите Claude оформить результат таблицей «проверка → ожидание → результат». Это заготовка для отчётов о проверке, которые пригодятся в модуле 6.

## Критерий выполнения

Задача выполнена, если Claude сам провёл минимум три проверки в браузере и его результаты совпали с вашими.

## Подсказки

- Если Claude «проверил» по коду, не открывая браузер, — скажите прямо: «через браузер, а не по коду». Инструмент есть, но выбирать его Claude не обязан.
- Разрешение на действия браузера можно выдать на всю сессию, как с правками файлов. Для чужих сайтов лучше подтверждать по одному.
