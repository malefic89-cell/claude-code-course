## Цель

Провести ещё одну фичу через полный цикл «ветка → PR → ревью → слияние» самостоятельно и привести историю в читаемый вид.

## Инструкция (пошагово)

1. Возьмите следующий пункт из `TODO.md`. Ветка, plan mode, реализация с подтверждением правок, коммит руками Claude, PR, ревью Claude плюс своё, правки, слияние. Без подсказок из задач модуля — по памяти; если что-то забылось, вернитесь к нужной задаче.
2. Посмотрите историю main:
   ```bash
   git log --oneline
   ```
   С 05-07 и ниже — одиночные коммиты, выше — коммиты слияния PR, по одному на фичу. История читается как список того, что умеет «Полка».
3. Попросите Claude собрать из истории `CHANGELOG.md`: версия, дата, список фич по PR. Прочитайте, поправьте, закоммитьте через PR — да, тоже через PR.
4. Обновите `TODO.md` и добавьте в CLAUDE.md правило: «Любое изменение — через ветку и PR».

## Критерий выполнения

Задача выполнена, если в main влиты минимум три PR (теги, конфликт из 06-06, фича этой задачи), есть `CHANGELOG.md`, и вы прошли цикл без подсказок.

## Подсказки

- Если цикл кажется долгим для маленькой правки — так и есть. В личном проекте правило «всё через PR» можно смягчить: PR для фич, прямой коммит для опечаток. Но решение должно быть записано в CLAUDE.md, а не приниматься каждый раз заново.
- `CHANGELOG.md` пригодится в модуле 7: это текст для страницы «что нового».
