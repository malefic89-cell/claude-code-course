## Цель

Собрать всё, что накопилось с v1, в рабочую версию 2 и закрепить её коммитом.

## Инструкция (пошагово)

1. Проверьте, что в «Полке» есть: обложки по ссылке (04-07), сортировка и экспорт (05-02), данные в `data/cards.json` с собственным CLAUDE.md (05-04). Чего-то нет — доделайте по циклу модуля 3.
2. Откройте `TODO.md` из 03-09 и выберите один пункт, который влезает в полчаса. Спланируйте его в plan mode и решите сами, нужен ли субагент (05-06).
3. Реализуйте с подтверждением правок.
4. Проверку поручите Claude через браузер (модуль 4) и продублируйте руками для одного случая.
5. Обновите `TODO.md`: что сделано, что осталось. Коммит:
   ```bash
   git add -A
   git commit -m "Полка v2"
   ```

## Критерий выполнения

Задача выполнена, если «Полка» открывается и работает со всеми фичами модулей 4–5, `git log --oneline` показывает коммит «Полка v2», а `TODO.md` актуален.

## Подсказки

- Это последний коммит «в main напрямую». С модуля 6 каждая фича пойдёт через ветку, поэтому здесь важно оставить проект в чистом рабочем состоянии.
- Если в проекте накопились правки без коммитов — сначала разберите их: `git status`, `git diff`, коммит или откат. В модуле 6 чистое дерево понадобится с первой задачи.
