## Цель

Узнать, где Claude Code хранит настройки MCP и как посмотреть их из терминала и из сессии.

## Инструкция (пошагово)

1. Выйдите из сессии Claude (`/exit`) и в обычном терминале выполните:
   ```bash
   claude mcp list
   ```
   Список пуст или в нём только встроенные серверы — своих вы ещё не добавляли.
2. Посмотрите справку по командам MCP:
   ```bash
   claude mcp --help
   ```
   Найдите команды добавления, удаления и просмотра сервера.

   ![claude mcp --help: команды add, list, get и примеры подключения](/screenshots/04-01-mcp-help.png)
3. Обратите внимание на область действия (scope): сервер можно подключить для одного проекта, для всех проектов пользователя или записать в файл проекта, чтобы он достался всем, кто клонирует репозиторий.
4. Запустите `claude` и выполните `/mcp` — та же информация, но внутри сессии. Так вы будете проверять состояние серверов по ходу работы.

## Критерий выполнения

Задача выполнена, если вы можете назвать команду для добавления сервера и объяснить, чем отличаются области действия.

## Подсказки

- Область «проект» удобна для «Полки»: настройки лягут в `.mcp.json` рядом с кодом и попадут в git. Личные серверы с ключами — только в область пользователя.
- Точный синтаксис меняется от версии к версии; `claude mcp --help` всегда актуальнее любого курса.
