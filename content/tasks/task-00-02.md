## Цель

Научиться получать копию любого открытого проекта с GitHub и понять, что вместе с файлами скачивается его история.

## Инструкция (пошагово)

Большинство проектов, с которыми вы будете работать, уже лежат в репозиториях на GitHub. Скачать такой проект вместе с историей — это **клонировать** его. Аккаунт на GitHub для открытых проектов не нужен.

1. Откройте в браузере любой небольшой открытый репозиторий на GitHub. Если не знаете какой — подойдёт учебный репозиторий самого GitHub: [github.com/octocat/Spoon-Knife](https://github.com/octocat/Spoon-Knife). В нём всего три файла, в том числе `README.md`, который понадобится в следующих задачах.
2. Нажмите зелёную кнопку **Code**, выберите вкладку **HTTPS** и скопируйте ссылку. Она заканчивается на `.git`.

   ![Кнопка Code на GitHub: вкладка HTTPS и ссылка для клонирования](/screenshots/00-02-github-code.png)
3. В терминале выйдите из папки `claude-lab` на уровень выше: `cd ..`, затем `pwd` — путь **не должен** заканчиваться на `claude-lab`. Это важно: `claude-lab` уже репозиторий, а репозиторий внутри репозитория потом путает git. Теперь выполните, подставив свою ссылку:
   ```bash
   git clone https://github.com/пользователь/проект.git
   ```
   Git создаст рядом папку с именем проекта и скачает в неё все файлы.
4. Перейдите в неё (`cd проект`) и посмотрите историю:
   ```bash
   git log --oneline
   ```
   Каждая строка — одно сохранённое состояние проекта, **коммит**: короткий код и описание того, что изменилось. Это та самая история, которую пишут авторы проекта. Выйти из длинного списка — клавиша `q`.

   ![Клонирование Spoon-Knife рядом с claude-lab и история коммитов](/screenshots/00-02-clone-log.png)
5. Выполните `git status`. В свежескачанном проекте он покажет `nothing to commit, working tree clean`: файлы совпадают с последним коммитом.

## Критерий выполнения

Задача выполнена, если папка проекта скачана, `git log --oneline` показывает список коммитов, а `git status` сообщает `working tree clean`.

## Подсказки

- Если терминал ругается `fatal: destination path already exists` — папка с таким именем уже есть. Удалите её или клонируйте в другое место.
- Клонировать можно сколько угодно раз: это просто копия. Ваши эксперименты в копии никак не затронут оригинал на GitHub.
- В задаче 01-03 вы будете запускать Claude в настоящем проекте — эта скачанная папка для этого подойдёт.
