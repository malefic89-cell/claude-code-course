## Цель

Пройти цикл «нашёл в браузере → починил → проверил в браузере» целиком, без вашей ручной проверки.

## Инструкция (пошагово)

1. Внесите в «Полку» баг нарочно, чтобы было что искать. Например, попросите Claude в обычном режиме:
   ```
   Сделай так, чтобы поиск учитывал регистр букв. Ничего не коммить.
   ```
   Подтвердите правку. Теперь запрос «dark» не найдёт «Dark Souls».
2. В новой сессии (чтобы Claude не помнил, что сам сломал) поставьте задачу через plan mode:
   ```
   Пользователи жалуются, что поиск иногда не находит карточки. Проверь в браузере, найди причину и предложи план исправления.
   ```
3. Прочитайте план: Claude должен сначала воспроизвести проблему в браузере, потом искать причину в коде. Если он сразу лезет в код — поправьте план (навык 03-04).

   ![План после воспроизведения в браузере: причина найдена в app.js, исправление в одной функции](/screenshots/04-04-plan-reproduce.png)
4. Утвердите план с подтверждением правок, читайте diff.
5. После исправления попросите повторить проверку в браузере теми же запросами. Только после этого — коммит:
   ```bash
   git add -A
   git commit -m "Полка: поиск без учёта регистра"
   ```

## Критерий выполнения

Задача выполнена, если проблема была воспроизведена и перепроверена в браузере самим Claude, а исправление закоммичено.

## Подсказки

- Это тот же цикл, что в 03-07, только роль «проверяющего» перешла к Claude. Ваша роль — читать план и diff.
- Если Claude не может открыть локальный файл через браузер (некоторые серверы требуют адрес `http://`), попросите его поднять простой статический сервер и открыть страницу по адресу.
