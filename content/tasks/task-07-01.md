## Цель

Найти и починить то, что работало локально, но ломается на сайте, руками Claude через браузер.

## Инструкция (пошагово)

1. Попросите Claude проверить опубликованную «Полку» через браузер (модуль 4):
   ```
   Открой https://<ваш адрес>/ и проверь всё, что умеет «Полка»: карточки, форма, поиск, сортировка, экспорт, обложки. Список того, что не работает, без правок.
   ```
2. Типичные находки: пути к файлам с ведущим `/` (на Pages сайт лежит в подпапке репозитория), обложки по `http://` вместо `https://`, данные из `data/cards.json` не загружаются при открытии файла напрямую, но грузятся на сайте — или наоборот.
3. Для каждой находки — ветка, план, правка, PR, слияние. Маленькие правки можно собрать в один PR «prepare for Pages».
4. После слияния подождите деплой и попросите повторить проверку. Повторяйте, пока список пуст.
5. Проверьте сами с телефона: «Полка» должна открываться и работать на узком экране. Если нет — это ещё одна ветка.

## Критерий выполнения

Задача выполнена, если проверка Claude по опубликованному адресу не находит проблем, и «Полка» работает на телефоне.

## Подсказки

- Относительные пути (`styles.css`, `data/cards.json`) работают и локально, и на Pages. Абсолютные (`/styles.css`) — только там, где сайт в корне домена.
- Если Claude не может открыть сайт через MCP, проверьте руками по тому же списку; список — главное.
