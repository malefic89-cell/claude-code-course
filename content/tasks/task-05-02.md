## Цель

Сделать две независимые фичи «Полки» двумя субагентами одновременно и собрать результат.

## Инструкция (пошагово)

Из «задачи на вечер» в 03-08 остались этапы. Здесь берём две фичи, которые не пересекаются по файлам: сортировка карточек и экспорт коллекции в файл.

1. Зафиксируйте состояние: `git add -A` и `git commit -m "Перед параллельной работой"`.
2. В plan mode попросите разбить работу так, чтобы две части можно было делать одновременно:
   ```
   Нужны две фичи: сортировка карточек (по названию и по году) и экспорт коллекции в JSON-файл кнопкой. Спланируй так, чтобы две части делали два субагента параллельно и не правили одни и те же строки. Скажи, какие файлы кому достаются.
   ```
3. Прочитайте план: у каждой части свои функции и своя область в `index.html`. Если обе части претендуют на один блок — попросите развести.
4. Утвердите план. Claude запустит двух субагентов; в интерфейсе видны оба. Дождитесь обоих.
5. Проверьте итог: `git diff --stat`, затем «Полка» в браузере (сами или через MCP из модуля 4): сортировка работает, экспорт скачивает файл.
6. Коммит:
   ```bash
   git add -A
   git commit -m "Полка: сортировка и экспорт"
   ```

## Критерий выполнения

Задача выполнена, если обе фичи сделаны субагентами параллельно, работают, и изменение закоммичено одним коммитом.

## Подсказки

- Параллельность выгодна, только когда части независимы. Если план показывает, что обе фичи правят одну функцию, — лучше последовательно, это тема 05-06.
- Подтверждение правок от субагентов приходит в основную сессию по очереди. Читайте diff, как всегда: чей он — видно по описанию.
