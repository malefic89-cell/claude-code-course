## Цель

Убедиться, что на компьютере установлено всё необходимое для работы: терминал, Git и Node.js. Если чего-то нет — установить.

## Инструкция (пошагово)

1. Откройте терминал:
   - **Windows:** PowerShell (Пуск → введите «PowerShell»)
   - **macOS:** Terminal (Cmd+Space → «Terminal»)
   - **Linux:** любой привычный терминал
2. Проверьте Git:
   ```bash
   git --version
   ```
   Нет? Установите с git-scm.com (Windows/macOS) или через пакетный менеджер (`sudo apt install git` и т.п.).
3. Проверьте Node.js (нужна версия 18 или новее):
   ```bash
   node --version
   ```
   Нет или версия ниже 18? Установите LTS-версию с nodejs.org.
4. Проверьте npm (ставится вместе с Node.js):
   ```bash
   npm --version
   ```
5. После любых установок **закройте и заново откройте терминал**, затем повторите проверки.

## Критерий выполнения

Задача выполнена, если все три команды (`git --version`, `node --version`, `npm --version`) выводят номера версий, и версия Node.js — 18 или выше.

## Подсказки

Здесь разобраны только сбои. Если все три команды уже вывели номера версий — задача выполнена, и ничего из списка ниже вам не нужно.

- **`git --version` или `node --version` отвечает «command not found» либо «не является внутренней или внешней командой»** — программа не установлена. Поставьте её (Git — с git-scm.com, Node.js — с nodejs.org) и переходите к следующему пункту.
- **Установили, но команда всё равно «не найдена»** — закройте окно терминала и откройте заново. Установщик прописывает программу в системный путь, но уже открытые окна об этом не знают. Это самая частая причина, и она не означает, что установка не удалась.
- **На сайте Node.js непонятно, какую версию скачивать** — берите ту, что помечена LTS: это стабильная версия, её достаточно.
- **`node --version` показывает версию ниже 18** — установите LTS-версию поверх старой, удалять ничего не нужно. После установки перезапустите терминал и проверьте снова.
- **Нет прав на установку (рабочий компьютер лаборатории)** — обратитесь к администратору. Обходить ограничение самостоятельно не нужно.
