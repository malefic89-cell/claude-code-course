## Цель

Убедиться, что на компьютере установлен Node.js — он нужен, чтобы поставить Claude Code. Если его нет — установить.

## Инструкция (пошагово)

Терминал вы уже открывали в модуле 0, там же проверяли git. Здесь остаётся Node.js: Claude Code распространяется через npm, менеджер пакетов, который ставится вместе с Node.js.

1. Откройте терминал (PowerShell на Windows, Terminal на macOS — как в задаче 00-00).
2. Проверьте Node.js (нужна версия 18 или новее):
   ```bash
   node --version
   ```
   Нет или версия ниже 18? Установите LTS-версию с nodejs.org.
3. Проверьте npm (ставится вместе с Node.js):
   ```bash
   npm --version
   ```
4. После установки **закройте и заново откройте терминал**, затем повторите проверки.

## Критерий выполнения

Задача выполнена, если `node --version` и `npm --version` выводят номера версий, и версия Node.js — 18 или выше.

## Подсказки

Здесь разобраны только сбои. Если обе команды уже вывели номера версий — задача выполнена, и ничего из списка ниже вам не нужно.

- **`node --version` отвечает «command not found» либо «не является внутренней или внешней командой»** — Node.js не установлен. Поставьте его с nodejs.org и переходите к следующему пункту.
- **Установили, но команда всё равно «не найдена»** — закройте окно терминала и откройте заново. Установщик прописывает программу в системный путь, но уже открытые окна об этом не знают. Это самая частая причина, и она не означает, что установка не удалась.
- **На сайте Node.js непонятно, какую версию скачивать** — берите ту, что помечена LTS: это стабильная версия, её достаточно.
- **`node --version` показывает версию ниже 18** — установите LTS-версию поверх старой, удалять ничего не нужно. После установки перезапустите терминал и проверьте снова.
