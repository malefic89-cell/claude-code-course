## Цель

Убедиться, что на компьютере установлено всё необходимое для работы: терминал, Git и Node.js. Если чего-то нет — установить.

## Инструкция (пошагово)

1. Откройте терминал:
   - **Windows:** PowerShell (Пуск → введите «PowerShell»)
   - **macOS:** Terminal (Cmd+Space → «Terminal»)
   - **Linux:** любой привычный терминал
2. Проверьте Git:
   ```bash
   git --version
   ```
   Нет? Установите с git-scm.com (Windows/macOS) или через пакетный менеджер (`sudo apt install git` и т.п.).
3. Проверьте Node.js (нужна версия 18 или новее):
   ```bash
   node --version
   ```
   Нет или версия ниже 18? Установите LTS-версию с nodejs.org.
4. Проверьте npm (ставится вместе с Node.js):
   ```bash
   npm --version
   ```
5. После любых установок **закройте и заново откройте терминал**, затем повторите проверки.

## Критерий выполнения

Задача выполнена, если все три команды (`git --version`, `node --version`, `npm --version`) выводят номера версий, и версия Node.js — 18 или выше.

## Подсказки

- **Команда установлена, но «не найдена»** — почти всегда лечится перезапуском терминала. Установщики добавляют программы в системный путь, но открытые окна терминала об этом не знают.
- **Не знаете, что выбрать на сайте Node.js** — берите зелёную кнопку LTS, это стабильная версия.
- **Нет прав на установку (рабочий компьютер лаборатории)** — обратитесь к администратору.
