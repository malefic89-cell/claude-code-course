## Цель

Почувствовать проблему, которую решает CLAUDE.md: без него Claude не знает договорённостей вашего проекта и каждую сессию начинает «с нуля».

## Инструкция (пошагово)

1. Выберите проект **без** файла CLAUDE.md (или временно переименуйте существующий: `mv CLAUDE.md CLAUDE.md.bak`).
2. Запустите `claude` и задайте вопросы о договорённостях, например:
   - «На каком языке мы пишем сообщения коммитов?»
   - «Какой командой запускаются тесты в этом проекте?»
   - «Какие у нас правила именования компонентов?»
3. Обратите внимание: Claude либо честно скажет, что не знает, либо предположит по косвенным признакам — но это догадки, а не ваши правила.
4. Завершите сессию, запустите новую и повторите один вопрос — убедитесь, что ничего не «запомнилось».
5. Если переименовывали файл — верните его: `mv CLAUDE.md.bak CLAUDE.md`.

## Критерий выполнения

Задача выполнена, если вы можете одним-двумя предложениями сформулировать: какую информацию Claude не может узнать из кода и почему её нужно записать в файл.

## Подсказки

- Каждая сессия Claude Code начинается с чистого листа — «память» проекта живёт только в файлах.
- CLAUDE.md автоматически читается при старте сессии в папке проекта — это и есть механизм «памяти».
