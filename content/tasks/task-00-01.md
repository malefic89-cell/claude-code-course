## Цель

Понять, что такое git-репозиторий, и превратить обычную папку в репозиторий одной командой.

## Инструкция (пошагово)

Git — это история изменений для папки с файлами. Он запоминает, как выглядели файлы в каждый момент, который вы попросили сохранить, и умеет показать разницу или вернуть файлы к любому из этих моментов. Для работы с Claude Code это главная страховка: Claude меняет файлы быстро и много, а git позволяет видеть, что именно изменилось, и отменять неудачное.

Папка, за которой следит git, называется **репозиторий**. Дальше все задачи этого модуля делаются в одной учебной папке `claude-lab`, созданной в задаче 00-00.

1. В терминале перейдите в папку `claude-lab`, созданную в задаче 00-00, и проверьте `pwd`, что вы в ней.
2. Превратите папку в репозиторий:
   ```bash
   git init
   ```
   Git ответит что-то вроде `Initialized empty Git repository`. В папке появилась скрытая подпапка `.git` — там git хранит историю. Её не нужно открывать и менять.
3. Проверьте состояние:
   ```bash
   git status
   ```
   Ответ `No commits yet` и `nothing to commit` означает: репозиторий есть, история пока пустая, файлов нет.
4. Запустите `claude` в этой папке и попросите: «Создай файл index.html с простой страницей: заголовок "Моя лаборатория" и один абзац текста».
5. Выйдите из Claude (`/exit` или Ctrl+C) и снова выполните `git status`. Теперь git показывает `index.html` в списке `Untracked files` — он видит новый файл, но ещё не сохранил его в историю. Как сохранять, разберём в задаче про коммит.

## Критерий выполнения

Задача выполнена, если в папке `claude-lab` есть файл `index.html`, а `git status` показывает его как `Untracked`.

## Подсказки

- `git status` — самая частая команда в этом блоке. Она ничего не меняет, её можно вызывать сколько угодно.
- Создавать репозиторий нужно один раз на папку. Повторный `git init` в той же папке ничего не сломает, но и не нужен.
