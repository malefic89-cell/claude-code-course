## Цель

Добавить в «Полку» обложки-картинки по ссылке и проверить их в браузере руками Claude.

## Инструкция (пошагово)

В v1 обложка — эмодзи. Теперь карточка может иметь ссылку на картинку, а эмодзи остаётся запасным вариантом (правило из 02-05 продолжает действовать).

1. В plan mode поставьте задачу:
   ```
   Добавь карточкам необязательное поле «ссылка на обложку». Если ссылка есть — показывать картинку, если нет или картинка не загрузилась — эмодзи, как сейчас. Поле в форме добавления и редактирования. Существующие карточки не ломать.
   ```
2. Отревьюйте план по чек-листу 03-03. Обязательно: что происходит с битой ссылкой и с уже сохранёнными карточками в localStorage.
3. Реализуйте с подтверждением правок.
4. Проверку поручите браузеру: попросите Claude добавить карточку с настоящей ссылкой на картинку, карточку с битой ссылкой и убедиться, что первая показывает картинку, вторая — эмодзи.
5. Посмотрите сами и закоммитьте:
   ```bash
   git add -A
   git commit -m "Полка: обложки по ссылке"
   ```

## Критерий выполнения

Задача выполнена, если карточки показывают картинку по ссылке и эмодзи при её отсутствии, обе ситуации проверены Claude в браузере, изменение закоммичено.

## Подсказки

- Картинку с чужого сайта браузер может не показать из-за настроек этого сайта. Для проверки берите ссылку на картинку из открытого источника, например обложку с Wikimedia Commons.
- Это первая фича, которую Claude проверил сам. Дальше в курсе ручная проверка остаётся за вами только там, где сказано явно.
