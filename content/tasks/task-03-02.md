## Цель

Включить режим планирования и получить план вместо немедленных изменений в коде.

## Инструкция (пошагово)

1. В сессии Claude Code нажмите `Shift+Tab` дважды (при пустой строке ввода): первое нажатие включает режим автопринятия, второе — plan mode. Смотрите на индикатор режима внизу экрана.
2. Если сочетание не сработало (бывает на Windows и в tmux) — есть запасные способы: команда `/plan` или запуск сессии сразу в этом режиме: `claude --permission-mode plan`.
3. Убедившись, что plan mode включён, дайте первую настоящую фичу «Полки»:
   ```
   Добавь форму добавления карточки: название, подпись, обложка-эмодзи. Новые карточки сохраняются в localStorage и не пропадают при перезагрузке страницы.
   ```
4. Claude исследует проект и вернёт план: какие файлы затронет, в каком порядке, что учтёт. Файлы при этом не меняются — режим только для чтения.
5. Проверьте, что ни один файл не тронут: `git status` должен показать чистое дерево (задача 00-03).
6. Пока **не** утверждайте план — читать и править его будем в следующих задачах. Выйдите из plan mode (`Shift+Tab`).

## Критерий выполнения

Задача выполнена, если вы получили структурированный план и убедились, что ни один файл не изменился.

## Подсказки

- Plan mode — это режим «только чтение» на уровне инструментов: Claude физически не может менять файлы, пока вы не одобрите план.
- Индикатор текущего режима отображается в строке состояния — привыкайте на него поглядывать.
- Сочетания клавиш и названия режимов могут отличаться в вашей версии — при расхождении ориентируйтесь на `/help`.
