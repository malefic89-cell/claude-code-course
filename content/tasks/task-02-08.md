## Цель

Научиться распознавать типичные ошибки в CLAUDE.md и исправлять их.

## Инструкция (пошагово)

1. Прочитайте учебный файл в разделе ниже и скопируйте его в черновик, чтобы было что править.
2. Найдите в нём проблемы. Ищите как минимум такие типы:
   - **Противоречия** — правила, отменяющие друг друга;
   - **Пустые заклинания** — «пиши хороший код», которые ни на что не влияют;
   - **Дубли кода** — информация, которую Claude и так видит в файлах (список зависимостей);
   - **Устаревшее** — правила о том, чего уже нет;
   - **Шум** — история проекта и прочее, не влияющее на работу;
   - **Неработающие инструкции** — «спроси у Марины».
3. Перепишите файл: удалите лишнее, разрешите противоречия (выберите один вариант каждого правила), устаревшее уберите.
4. Сравните объём: хорошая версия обычно в 3–5 раз короче.

## Учебный файл: плохой CLAUDE.md

Скопируйте этот текст и правьте его в своём редакторе. Это анти-пример — так писать не нужно.

```markdown
# CLAUDE.md — Интернет-магазин «Ромашка» (УЧЕБНЫЙ АНТИ-ПРИМЕР — НЕ ИСПОЛЬЗОВАТЬ КАК ОБРАЗЕЦ)

## О проекте
Это очень важный проект. Пожалуйста, пиши качественный, чистый, хороший код без багов. Старайся изо всех сил. Код должен быть красивым и профессиональным. Не делай ошибок.

## Стек
- React (вроде бы 16-я версия, но может уже обновили)
- Мы планируем перейти на Vue в следующем году, поэтому пиши код так, чтобы легко было мигрировать
- jQuery для старых страниц
- Node.js

## Правила
- Все комментарии пиши на английском языке
- Комментарии в коде должны быть на русском, чтобы junior-разработчики понимали
- Используй TypeScript строго, никакого any
- Если TypeScript мешает — можно any, главное чтобы работало
- Пиши тесты
- Тесты пока не пишем, нет времени

## Полный список зависимостей
react, react-dom, react-router, react-router-dom, axios, lodash, moment, dayjs, classnames, styled-components, sass, webpack, babel-core, babel-loader, eslint, prettier, jest, testing-library, redux, redux-thunk, redux-saga, reselect, immer, formik, yup, uuid, qs, js-cookie...
(здесь было ещё 40 строк зависимостей, скопированных из package.json)

Спроси у Марины.

- НИКОГДА не трогай файл legacy/cart.js (устарело: cart.js удалён в 2023)
- Деплой по пятницам запрещён
- Деплоим только по пятницам после ревью
```

## Критерий выполнения

Задача выполнена, если вы можете назвать три разных типа проблем из исходного файла, и ваша исправленная версия не содержит противоречий.

## Подсказки

- Противоречия — худший из анти-паттернов: Claude вынужден угадывать, какое из двух правил настоящее, и будет вести себя непредсказуемо.
- Разрешая противоречие, не выбирайте наугад: если проект не только ваш, это повод спросить остальных, как на самом деле принято.
- Проверка на «заклинание»: можно ли по правилу однозначно сказать, нарушено оно или нет? «Пиши красиво» — нельзя, значит правило пустое.
