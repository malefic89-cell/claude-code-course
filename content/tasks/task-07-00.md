## Цель

Включить GitHub Pages для репозитория «Полки» и получить публичную ссылку.

## Инструкция (пошагово)

GitHub Pages показывает файлы из репозитория как сайт. «Полка» — это `index.html` без сборки, поэтому ей ничего не нужно, кроме включённого Pages.

1. Репозиторий должен быть публичным. Если в 06-01 вы сделали приватный — переключите: `gh repo edit --visibility public`.
2. Включите Pages из терминала:
   ```bash
   gh api -X POST repos/{owner}/{repo}/pages -f build_type=legacy -f source[branch]=main -f source[path]=/
   ```
   Если команда пугает — то же самое кнопками: Settings → Pages → Source: Deploy from a branch → main, папка `/ (root)`.
3. Подождите минуту-две и откройте адрес вида `https://<логин>.github.io/<репозиторий>/`. Точный адрес показан в Settings → Pages.
4. Если вместо «Полки» страница 404 — подождите ещё, первый деплой бывает медленным. Если 404 держится — проверьте, что файл называется `index.html` и лежит в корне.
5. Запишите ссылку в `README.md` репозитория первой строкой и закоммитьте через PR (правило из 06-07).

## Критерий выполнения

Задача выполнена, если «Полка» открывается по адресу `github.io` с другого устройства или из приватного окна браузера.

## Подсказки

- Pages обновляется сам при каждом изменении main; ждать нужно до минуты.
- Данные карточек живут в localStorage браузера посетителя: у каждого, кто откроет ссылку, будет своя пустая полка со стартовыми карточками. Это нормально для v2; общая база — тема после курса.
