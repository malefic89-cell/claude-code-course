## Цель

Провести ревью собственного PR двумя способами и поручить Claude первый проход.

## Инструкция (пошагово)

1. На GitHub во вкладке Files changed пройдите diff с чек-листом из 03-03: лишние файлы, изменения не по теме, непонятные названия. Оставьте минимум один комментарий к строке (кнопка «+» у строки).
2. В терминале попросите Claude сделать ревью:
   ```
   Сделай ревью PR этой ветки: ошибки, лишние изменения, что можно упростить. Не правь, только список.
   ```
   Claude прочитает diff (`gh pr diff`) и вернёт список замечаний.
3. Сравните два списка: свой и Claude. Что нашли оба, что только вы, что только он.
4. Выберите из объединённого списка два замечания, которые стоит исправить. Остальные — осознанно отклоните, написав почему (одной строкой в комментарии PR).
5. Замечания к исправлению оставьте на следующую задачу.

## Критерий выполнения

Задача выполнена, если у PR есть минимум один ваш комментарий к строке, список замечаний от Claude, и вы выбрали, что исправлять.

## Подсказки

- Ревью Claude хорошо ловит формальное: неиспользуемые переменные, дубли, несоответствие CLAUDE.md. Хуже — «это не то, что я хотел». Второе только ваше.
- Замечание, которое вы решили не исправлять, всё равно стоит записать: через месяц вы не вспомните, почему.
