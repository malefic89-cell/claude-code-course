## Цель

Понять, что Claude Code видит файлы проекта, в котором запущен, и умеет отвечать на вопросы о них.

## Инструкция (пошагово)

1. Выберите папку с любым реальным проектом — рабочим или учебным. Если такого под рукой нет, склонируйте любой небольшой открытый репозиторий с GitHub:
   - На странице репозитория нажмите зелёную кнопку **Code**, выберите вкладку **HTTPS** и скопируйте ссылку вида `https://github.com/пользователь/проект.git`.
   - В терминале перейдите в папку, где хотите разместить проект, и выполните — подставив скопированную ссылку:
     ```bash
     git clone https://github.com/пользователь/проект.git
     ```
   - Git создаст рядом папку с именем проекта. Перейдите в неё: `cd проект`.

   Аккаунт GitHub для этого не нужен — публичные репозитории клонируются без входа. Git у вас уже установлен: его наличие проверялось в задаче 01-00.
2. Перейдите в папку проекта и запустите `claude`.
3. Попросите описать проект, например: «Опиши структуру этого проекта: что это, из чего состоит, где точка входа».
4. Задайте уточняющий вопрос про конкретный файл, например: «Что делает файл package.json?» (или любой файл вашего проекта).
5. Обратите внимание: чтобы ответить, Claude сам читает файлы — вы увидите это в выводе.

## Критерий выполнения

Задача выполнена, если Claude перечислил реальные файлы/папки вашего проекта и ответил на вопрос об одном конкретном файле.

## Подсказки

- Claude Code работает в пределах папки, где запущен. Запускайте его в корне проекта, а не в домашней директории.
- Если проект большой и ответ кажется поверхностным — попросите сузить: «Разбери только папку src».
- На этом шаге ничего менять не нужно — только вопросы. Первую правку сделаем в задаче 01-06.
