## Цель

Авторизоваться и провести первый диалог с Claude Code.

## Инструкция (пошагово)

1. Создайте пустую папку для экспериментов и перейдите в неё — две команды по очереди:
   ```bash
   mkdir claude-sandbox
   cd claude-sandbox
   ```
2. Запустите Claude Code:
   ```bash
   claude
   ```
3. При первом запуске откроется авторизация — войдите через аккаунт Claude (подписка) или Claude Console (API). Следуйте подсказкам в браузере.
4. Вернувшись в терминал, дождитесь приглашения к вводу.
5. Отправьте первое сообщение, например: «Привет! Расскажи коротко, что ты умеешь».
6. Прочитайте ответ. Выйти из сессии можно командой `/exit` или сочетанием Ctrl+C (дважды).

   ![Первая сессия Claude Code: приглашение к вводу, ваш вопрос и ответ](/screenshots/01-02-first-run.png)

## Критерий выполнения

Задача выполнена, если вы отправили сообщение, получили ответ и вышли из сессии.

## Подсказки

- Если браузер не открылся автоматически, скопируйте ссылку из терминала вручную.
- Каких-либо файлов на этом шаге не создаётся — это просто разговор. Работа с проектом начнётся в следующей задаче.
- **Аккаунт.** Нужен один из двух: подписка Claude (Pro и выше, вход через claude.ai) или аккаунт Claude Console с API-ключом (оплата по расходу). Для курса хватит любого; если ещё ничего нет — подписка проще.
- **Россия.** Anthropic официально не работает в России: сайт claude.ai, регистрация и сам Claude Code без VPN не откроются. Держите VPN включённым на всё время работы, а не только на момент входа; для оплаты подписки или API понадобится карта не российского банка.
