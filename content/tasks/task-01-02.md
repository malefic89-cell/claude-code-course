## Цель

Авторизоваться и провести первый диалог с Claude Code.

## Инструкция (пошагово)

1. Создайте пустую папку для экспериментов и перейдите в неё:
   ```bash
   mkdir claude-sandbox && cd claude-sandbox
   ```
2. Запустите Claude Code:
   ```bash
   claude
   ```
3. При первом запуске откроется авторизация — войдите через аккаунт Claude (подписка) или Claude Console (API). Следуйте подсказкам в браузере.
4. Вернувшись в терминал, дождитесь приглашения к вводу.
5. Отправьте первое сообщение, например: «Привет! Расскажи коротко, что ты умеешь».
6. Прочитайте ответ. Выйти из сессии можно командой `/exit` или сочетанием Ctrl+C (дважды).

## Критерий выполнения

Задача выполнена, если вы отправили сообщение, получили ответ и вышли из сессии.

## Подсказки

- Если браузер не открылся автоматически, скопируйте ссылку из терминала вручную.
- Каких-либо файлов на этом шаге не создаётся — это просто разговор. Работа с проектом начнётся в следующей задаче.
- Тип аккаунта (подписка или API) уточните у автора курса — в лаборатории используется единый способ входа.
