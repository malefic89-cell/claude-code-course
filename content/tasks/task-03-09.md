## Цель

Довести «Полку» до первой версии, которой можно пользоваться, самостоятельно применив всё из модулей 1–3: CLAUDE.md, plan mode, ревью, итерации, проверку.

## Инструкция (пошагово)

1. Проверьте, что в «Полке» есть всё, что делалось по ходу модулей: карточка-пример (01-06), CLAUDE.md (модуль 2), форма добавления с сохранением в localStorage (03-05), поиск (03-07), первый этап редактирования и удаления (03-08). Чего нет — доделайте по полному циклу 03-07.
2. В plan mode попросите план «довести v1 до состояния, которым можно пользоваться»: пустое состояние («полка пуста, добавьте первую карточку»), защита от пустого названия, аккуратный вид на узком экране телефона. Отревьюйте по чек-листу 03-03, внесите минимум одну правку (03-04).
3. Утвердите план и реализуйте, читая каждый diff (03-05, 03-06).
4. Проверьте руками, как в 03-07: закройте браузер и откройте `index.html` заново — карточки на месте; попробуйте добавить карточку с пустым названием — форма не должна её принять; сузьте окно до ширины телефона. Нашли проблему — прогоните через цикл исправления.
5. Сохраните версию:
   ```bash
   git add -A
   git commit -m "Shelf v1"
   ```
   `git log --oneline` покажет всю историю продукта, начиная с первого коммита в 01-06.
6. Запишите в `TODO.md`, что хотите добавить дальше: обложки-картинки, теги, экспорт, что угодно. Это станет материалом для следующих модулей — «Полка» продолжится.

## Критерий выполнения

Задача выполнена, если: `index.html` открывается двойным кликом; карточки добавляются, ищутся и переживают перезагрузку; в проекте есть осмысленный CLAUDE.md; `git status` чист, а в истории есть коммит «Shelf v1»; вы можете назвать минимум одно отклонение реализации от плана (или обоснованно сказать, что их не было).

## Подсказки

- Если после перезагрузки карточки пропадают — почти всегда данные сохраняются в localStorage, но не читаются при загрузке страницы. Так и опишите проблему Claude: что сделали, что ожидали, что увидели.
- Это не выпускная задача. Дальше та же «Полка» получит проверку через MCP, параллельные фичи субагентами, ветки и pull request, а в конце — публикацию по ссылке.
