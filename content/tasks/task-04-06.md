## Цель

Научиться диагностировать неработающий MCP-сервер и отключать ненужные.

## Инструкция (пошагово)

1. Сломайте подключение нарочно: удалите сервер `files` из 04-05 и добавьте его заново с опечаткой в имени пакета:
   ```bash
   claude mcp remove --scope user files
   claude mcp add --scope user files -- npx -y @modelcontextprotocol/server-filesystm C:\Learning
   ```
2. Запустите `claude` и выполните `/mcp`. Найдите сервер со статусом ошибки и откройте подробности — там текст ошибки запуска.
3. Прочитайте ошибку: npx не нашёл пакет с таким именем. Удалите сервер и добавьте заново с правильным именем (команда из 04-05). Проверьте `/mcp`.
4. Отключите браузерный сервер, не удаляя: найдите в `/mcp` переключатель или временно уберите его из области проекта. Убедитесь, что Claude снова не может открыть страницу.
5. Включите обратно — он понадобится в 04-07.

## Критерий выполнения

Задача выполнена, если вы починили сломанный сервер по тексту ошибки из `/mcp` и умеете отключать сервер без удаления.

## Подсказки

- Типичные причины: не установлен Node.js или пакет, неверный путь, отсутствует переменная окружения с ключом, сервер требует другую версию.
- Много подключённых серверов замедляют старт сессии и засоряют контекст списком инструментов. Держите включёнными только те, что нужны в текущей работе.
