## Цель

Завести репозиторий «Полки» на GitHub и отправить туда историю — первый `git push` в курсе.

## Инструкция (пошагово)

До сих пор аккаунт GitHub не требовался: в 00-02 вы клонировали чужой проект без входа. Теперь нужен свой аккаунт — создайте его на github.com, если ещё нет.

1. Установите `gh`, консольный клиент GitHub (ссылка в подсказках), и войдите:
   ```bash
   gh auth login
   ```
   Выбирайте GitHub.com, HTTPS, вход через браузер. Вводить пароль в терминале не нужно.
2. В папке «Полки», в ветке `main`, создайте репозиторий и отправьте историю:
   ```bash
   gh repo create --source=. --public --push
   ```
   Имя репозитория `gh` возьмёт из имени папки; согласитесь или задайте своё.
3. Откройте репозиторий в браузере: `gh repo view --web`. Все коммиты с 00-01 до «Shelf v2» на месте, файлы читаются.
4. Проверьте связь: `git remote -v` показывает адрес репозитория. Слово `origin` — его имя по умолчанию.
5. Отправьте и ветку из 06-00:
   ```bash
   git switch feature/tags
   git push -u origin feature/tags
   ```

## Критерий выполнения

Задача выполнена, если репозиторий открывается на GitHub, в нём вся история «Полки», и обе ветки видны на вкладке Branches.

## Подсказки

- Установка `gh`: cli.github.com — есть установщик для Windows и `brew install gh` для macOS.
- Публичный репозиторий увидят все. Если в «Полке» есть что-то личное — сделайте `--private`; для модуля 7 публичность понадобится, но это решаемо позже.
- `-u` в `git push -u` запоминает связь ветки с удалённой; дальше хватит просто `git push`.
