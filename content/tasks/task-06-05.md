## Цель

Исправить замечания в той же ветке, обновить PR и влить его в main.

## Инструкция (пошагово)

1. В ветке `feature/tags` дайте Claude два замечания из 06-04 одним сообщением. Подтвердите правки, читая diff.
2. Попросите закоммитить (правило из 06-02) и отправить ветку: `git push`. Откройте PR на GitHub — новый коммит появился в нём сам, diff обновился.
3. Ответьте на свой комментарий к строке: «исправлено в таком-то коммите» — и закройте обсуждение (Resolve).
4. Влейте PR:
   ```bash
   gh pr merge --squash --delete-branch
   ```
   `--squash` собирает коммиты ветки в один в main, `--delete-branch` удаляет ветку после слияния.
5. Вернитесь в main и заберите результат:
   ```bash
   git switch main
   git pull
   git log --oneline -3
   ```
   Первой строкой — коммит слияния с названием PR.

## Критерий выполнения

Задача выполнена, если PR влит, ветка удалена, а в `main` на GitHub и локально есть фича с тегами.

## Подсказки

- `--squash` или обычный merge — дело вкуса; squash даёт чистую историю «одна фича — один коммит», что удобно читать в модуле 7.
- Если `gh pr merge` отказывается из-за конфликта — это тема следующей задачи; не форсируйте.
