## Цель

Научиться сохранять состояние проекта в историю, чтобы к нему можно было вернуться, — руками и через Claude.

## Инструкция (пошагово)

Сохранённая точка в истории называется **коммит**. Сделать коммит — значит сказать git: «запомни, как файлы выглядят сейчас, и подпиши это одной фразой». Пока коммита нет, изменения существуют только в файлах и откатиться к «как было до правки Claude» не к чему.

Коммит делается в два шага: сначала выбрать, какие файлы сохранять (`git add`), потом сохранить (`git commit`). Для начала всегда сохраняйте всё сразу.

1. Продолжайте в проекте из задачи 00-03: там есть изменённый `README.md`.
2. Отметьте все изменения для сохранения:
   ```bash
   git add -A
   ```
   Команда ничего не выводит — это нормально. `git status` теперь покажет файл в `Changes to be committed`.
3. Сохраните с подписью:
   ```bash
   git commit -m "Add learning note to README"
   ```
   Подпись пишется в кавычках, коротко, о том, что сделано. Язык любой; в этом курсе мы пишем по-английски, потому что так принято в большинстве проектов.
4. Проверьте: `git log --oneline` показывает ваш коммит первой строкой, `git status` снова говорит `working tree clean`.
5. Теперь то же самое через Claude. Запустите `claude`, попросите ещё одну маленькую правку (например, «добавь в README.md второй абзац с текстом "Проверка коммита"»), а затем: «Сделай коммит с этими изменениями». Claude выполнит `git add` и `git commit` сам и покажет команды.
6. Выйдите из Claude и убедитесь по `git log --oneline`, что коммитов стало два.

## Критерий выполнения

Задача выполнена, если `git log --oneline` показывает два новых коммита: один сделан вами руками, второй — через Claude.

## Подсказки

- Если на `git commit` git просит представиться (`Please tell me who you are`), выполните две команды по очереди, подставив своё имя и почту (они попадут только в историю на вашем компьютере), и повторите коммит:
  ```bash
  git config --global user.name "Имя"
  git config --global user.email "you@example.com"
  ```
- Если `git commit` открыл редактор вместо того, чтобы сразу сохранить, — вы забыли `-m "..."`. Закройте редактор (в Vim: `Esc`, затем `:q!`, Enter) и повторите команду с подписью.
- Сколько коммитов делать? Хорошее правило для работы с Claude: коммит после каждого удачного шага. Тогда откатить можно ровно один неудачный шаг, а не всю сессию.
- Коммит хранится только на вашем компьютере. Отправка на GitHub — отдельная команда `git push`, она в этом блоке не нужна.
