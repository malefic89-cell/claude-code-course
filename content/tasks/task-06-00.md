## Цель

Понять, что такое ветка, и создать первую ветку в «Полке» руками.

## Инструкция (пошагово)

В модуле 0 история «Полки» была одной линией коммитов. Ветка — ответвление от этой линии: в ней можно делать фичу, ломать и чинить, а main остаётся рабочим. Когда фича готова, ветка вливается в main. С этого модуля каждая фича «Полки» идёт через ветку.

1. В «Полке» проверьте, что дерево чистое: `git status` → `working tree clean`. Если нет — разберите правки (05-07).
2. Посмотрите, в какой ветке вы сейчас:
   ```bash
   git branch
   ```
   Звёздочка у `main` (или `master` — так git назвал ветку при `git init`; переименуйте: `git branch -M main`).
3. Создайте ветку и перейдите в неё одной командой:
   ```bash
   git switch -c feature/tags
   ```
4. Снова `git branch`: звёздочка переехала. Файлы не изменились — ветка пока указывает на тот же коммит.
5. Вернитесь в main: `git switch main`. И обратно: `git switch feature/tags`. Переключение мгновенное, пока в ветках нет разных коммитов.

## Критерий выполнения

Задача выполнена, если `git branch` показывает две ветки, и вы умеете переключаться между ними.

## Подсказки

- Имя ветки — про фичу: `feature/tags`, `fix/search-case`. Не про день или человека.
- `git switch` появился в git 2.23; если команда не найдена — `git checkout -b feature/tags` делает то же.
