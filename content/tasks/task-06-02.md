## Цель

Сделать фичу в ветке и поручить коммит Claude — по правилу о сообщениях из CLAUDE.md.

## Инструкция (пошагово)

1. Добавьте в CLAUDE.md «Полки» правило о коммитах, если его нет (02-05): язык сообщений, формат, например: «Сообщения коммитов на английском, первая строка до 60 символов, начинается с глагола».
2. В ветке `feature/tags` через plan mode сделайте фичу: теги у карточек и фильтр по тегу (этап из 03-08, если ещё не сделан; иначе возьмите следующий пункт из `TODO.md`). Подтверждайте правки по одной.
3. Когда фича работает, попросите:
   ```
   Закоммить изменения. Сообщение — по правилу из CLAUDE.md.
   ```
4. Claude покажет `git status` и `git diff`, предложит сообщение и попросит разрешение на `git commit`. Прочитайте сообщение: соответствует правилу? Если нет — отклоните и поправьте правило, а не сообщение.
5. Проверьте `git log --oneline -3` и отправьте ветку: `git push`.

## Критерий выполнения

Задача выполнена, если в ветке есть коммит с сообщением, написанным Claude по правилу из CLAUDE.md, и ветка отправлена на GitHub.

## Подсказки

- Claude добавляет к коммиту строку о своём участии. Это нормально и честно: по истории видно, что делалось с помощью ИИ.
- Не давайте разрешение «на все команды git» на сессию. `git commit` безопасен, а `git push --force` или `git reset --hard` — нет; пусть спрашивает.
