## Цель

Установить Claude Code и убедиться, что он готов к работе.

## Инструкция (пошагово)

1. Выполните `npm install -g @anthropic-ai/claude-code`.
2. Перезапустите терминал.
3. Проверьте: `claude --version`.

## Критерий выполнения

Задача выполнена, если `claude --version` выводит номер версии без ошибок.

## Подсказки

- На Windows при «not recognized» проверьте, что папка из `npm config get prefix` есть в Path.
