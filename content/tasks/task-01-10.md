## Цель

Научиться отменять правки, сделанные через Claude Code, — чтобы не бояться экспериментировать.

## Инструкция (пошагово)

1. Работайте в учебном проекте. Сделайте коммит, чтобы зафиксировать исходное состояние (задача 00-04).
2. Попросите Claude внести заметную правку в файл. Когда он покажет diff, разрешите правку — так же, как в задаче 01-06. «Подтвердить» здесь означает ответить «да» на запрос Claude, а не сделать коммит в git: это разные вещи.
3. Откатите изменение одним из способов:
   - командой `/rewind` — выберите точку до правки (Claude Code сохраняет чекпойнты);
   - или просто попросите: «Отмени последнее изменение, верни файл к прежнему виду»;
   - или средствами git — `git restore имя_файла`, как в задаче 00-05.
4. Убедитесь, что файл вернулся к исходному состоянию.

## Критерий выполнения

Задача выполнена, если после отката содержимое файла совпадает с исходным, и вы попробовали минимум один способ отката.

## Подсказки

- `/rewind` откатывает к чекпойнту; какие именно состояния доступны — смотрите в списке, который показывает команда. Поведение чекпойнтов уточняйте в актуальной документации: этот механизм активно развивается.
- Самая надёжная страховка — git: коммит перед серией правок делает любой эксперимент обратимым. `/rewind` и просьба «отмени» удобнее, но зависят от Claude; git работает всегда.
