## Цель

Научиться добавлять правила в CLAUDE.md прямо из диалога, не открывая редактор, и знать, где Claude Code хранит память.

## Инструкция (пошагово)

1. Запустите `claude` в «Полке» — CLAUDE.md там уже есть после задачи 02-02.
2. Представьте типичную ситуацию: Claude сделал что-то не так, как вы хотели, и вы не хотите повторять поправку в каждой сессии. Напишите правило словами «запомни» и явно попросите положить его в файл, например:
   ```
   Запомни на будущее: если у карточки нет обложки, показывай эмодзи, а не пустое место. Добавь это правило в CLAUDE.md.
   ```
3. Claude предложит правку CLAUDE.md и спросит разрешение, как в задаче 01-06. Прочитайте diff: куда именно в файле попадает правило и как Claude его сформулировал. Подтвердите.

   ![Claude правит CLAUDE.md: правило встало в раздел «Правила», ниже вопрос о разрешении](/screenshots/02-05-remember.png)
4. Откройте CLAUDE.md (`notepad CLAUDE.md`, на macOS `open -e CLAUDE.md`) и найдите правило. Это стоит сделать один раз именно глазами: записанная формулировка может отличаться от вашей, а место в файле — быть не тем, где вы бы его искали.
5. Выполните `/memory`. Команда показывает все файлы памяти, которые Claude видит в этой сессии: проектный CLAUDE.md, глобальный (о нём — задача 02-06) и заметки, которые Claude Code ведёт сам. Так вы всегда можете проверить, откуда взялось то или иное правило.

## Критерий выполнения

Задача выполнена, если правило, продиктованное в диалоге, появилось в файле CLAUDE.md без ручного редактирования, а `/memory` показывает этот файл в списке.

## Подсказки

- «Запомни» без «добавь в CLAUDE.md» Claude может понять как просьбу помнить в рамках текущего разговора. Слово «CLAUDE.md» в запросе убирает двусмысленность.
- Claude Code умеет и сам сохранять заметки о проекте между сессиями (автопамять). Это удобно, но такие заметки не заменяют CLAUDE.md: файл — единственное место, которое вы контролируете целиком и которое попадает в git вместе с проектом.
- Раз в пару недель полезно перечитывать накопленные правила: быстрые заметки имеют свойство устаревать и дублироваться.
