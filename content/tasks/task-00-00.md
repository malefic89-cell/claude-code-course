## Цель

Научиться понимать, в какой папке находится терминал, и переходить в нужную. Без этого ни git, ни Claude Code не заработают: оба действуют в той папке, где их запустили.

## Инструкция (пошагово)

Терминал всегда «стоит» в какой-то папке — это его **текущая папка**. Все команды выполняются относительно неё: `git init` создаст репозиторий именно здесь, `claude` увидит именно эти файлы. Поэтому первый вопрос перед любой командой — «где я?».

1. Откройте терминал (как — в задаче 01-00: PowerShell на Windows, Terminal на macOS). Спросите, где вы:
   ```bash
   pwd
   ```
   Ответ — полный путь к текущей папке, например `C:\Users\Имя` или `/Users/имя`. Сразу после открытия терминал обычно стоит в вашей домашней папке.
2. Посмотрите, что в ней лежит:
   ```bash
   ls
   ```
   Это те же файлы и папки, что вы видите в проводнике или Finder.
3. Перейдите в одну из папок из списка, например в «Документы» (на Windows она называется `Documents`):
   ```bash
   cd Documents
   ```
   Снова `pwd` — путь изменился. Совет: наберите `cd Doc` и нажмите Tab — терминал допишет имя сам. Так же он дописывает любые имена файлов и папок; пользуйтесь этим постоянно, чтобы не делать опечаток.
4. Вернитесь на уровень выше:
   ```bash
   cd ..
   ```
   Две точки означают «родительская папка». `cd ../..` поднимает на два уровня.
5. Перейдите в папку по полному пути — это работает из любого места. Скопируйте путь к любой своей папке из адресной строки проводника (Windows) или перетащите папку в окно терминала (macOS) и выполните:
   ```bash
   cd "C:\Users\Имя\Documents\Проекты"
   ```
   Кавычки обязательны, если в пути есть пробелы. Без них терминал решит, что вы передали несколько разных слов.
6. Создайте папку для учебных проектов и перейдите в неё — она понадобится в следующей задаче:
   ```bash
   mkdir claude-lab
   cd claude-lab
   ```
   Проверьте `pwd`: путь должен заканчиваться на `claude-lab`.

## Критерий выполнения

Задача выполнена, если вы можете из любой папки перейти в `claude-lab` командой `cd` и `pwd` показывает путь к ней.

## Подсказки

- Заблудились — `cd ~` (на Windows тоже работает) возвращает в домашнюю папку, оттуда можно начать заново.
- `cd: no such file or directory` или `Cannot find path` — такой папки здесь нет. Проверьте `ls`: вы, возможно, не там, где думаете, или в имени опечатка.
- Быстрый способ открыть терминал сразу в нужной папке: на Windows в проводнике щёлкните адресную строку, наберите `powershell` и нажмите Enter; на macOS в Finder щёлкните папку правой кнопкой — «Новый терминал в папке» (включается в настройках, раздел «Службы»).
- На Windows буква диска — часть пути: `cd D:\Projects` перейдёт на другой диск.
- Все папки, которые вы создаёте в терминале, видны в проводнике, и наоборот. Терминал — просто другой способ ходить по тем же папкам.
