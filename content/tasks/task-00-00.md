## Цель

Открыть терминал, убедиться, что установлен git, и научиться понимать, в какой папке находится терминал, и переходить в нужную. Без этого ни git, ни Claude Code не заработают: оба действуют в той папке, где их запустили.

## Инструкция (пошагово)

Терминал всегда «стоит» в какой-то папке — это его **текущая папка**. Все команды выполняются относительно неё: `git init` создаст репозиторий именно здесь, `claude` увидит именно эти файлы. Поэтому первый вопрос перед любой командой — «где я?».

1. Откройте терминал:
   - **Windows:** PowerShell (Пуск → введите «PowerShell»)
   - **macOS:** Terminal (Cmd+Space → «Terminal»)
   - **Linux:** любой привычный терминал
2. Проверьте, что установлен git:
   ```bash
   git --version
   ```
   Должен появиться номер версии. Если вместо него «command not found» или «не является внутренней или внешней командой» — установите git с git-scm.com (Windows/macOS) или через пакетный менеджер (`sudo apt install git` и т.п.), затем **закройте и заново откройте терминал** и повторите проверку.
3. Спросите, где вы:
   ```bash
   pwd
   ```
   Ответ — полный путь к текущей папке, например `C:\Users\Имя` или `/Users/имя`. Сразу после открытия терминал обычно стоит в вашей домашней папке; если вы открыли его из конкретной папки, путь будет другим — это нормально.
4. Посмотрите, что в ней лежит:
   ```bash
   ls
   ```
   Это те же файлы и папки, что вы видите в проводнике или Finder.

   ![Проверка git, затем pwd и ls: так выглядят первые три команды](/screenshots/00-00-terminal.png)
5. Перейдите в одну из папок из списка, например в «Документы» (на Windows она называется `Documents`):
   ```bash
   cd Documents
   ```
   Снова `pwd` — путь изменился. Совет: наберите `cd Doc` и нажмите Tab — терминал допишет имя сам. Так же он дописывает любые имена файлов и папок; пользуйтесь этим постоянно, чтобы не делать опечаток.
6. Вернитесь на уровень выше:
   ```bash
   cd ..
   ```
   Две точки означают «родительская папка». `cd ../..` поднимает на два уровня.
7. Перейдите в папку по полному пути — это работает из любого места. Скопируйте путь к любой своей папке из адресной строки проводника (Windows) или перетащите папку в окно терминала (macOS) и выполните:
   ```bash
   cd "C:\Users\Имя\Documents\Проекты"
   ```
   Кавычки обязательны, если в пути есть пробелы. Без них терминал решит, что вы передали несколько разных слов.
8. Создайте папку для учебных проектов и перейдите в неё — она понадобится в следующей задаче:
   ```bash
   mkdir claude-lab
   cd claude-lab
   ```
   Проверьте `pwd`: путь должен заканчиваться на `claude-lab`.

   ![Папка создана, терминал стоит в ней: путь в приглашении заканчивается на claude-lab](/screenshots/00-00-claude-lab.png)

## Критерий выполнения

Задача выполнена, если `git --version` выводит номер версии, а вы можете из любой папки перейти в `claude-lab` командой `cd`, и `pwd` показывает путь к ней.

## Подсказки

- **Установили git, но команда всё равно «не найдена»** — закройте окно терминала и откройте заново: уже открытые окна не знают о новой программе. Это самая частая причина, и она не означает, что установка не удалась.
- Заблудились — `cd ~` (на Windows тоже работает) возвращает в домашнюю папку, оттуда можно начать заново.
- `cd: no such file or directory` или `Cannot find path` — такой папки здесь нет. Проверьте `ls`: вы, возможно, не там, где думаете, или в имени опечатка.
- Быстрый способ открыть терминал сразу в нужной папке: на Windows в проводнике щёлкните адресную строку, наберите `powershell` и нажмите Enter; на macOS в Finder щёлкните папку правой кнопкой — «Новый терминал в папке» (включается в настройках, раздел «Службы»).
- На Windows буква диска — часть пути: `cd D:\Projects` перейдёт на другой диск.
- Все папки, которые вы создаёте в терминале, видны в проводнике, и наоборот. Терминал — просто другой способ ходить по тем же папкам.
