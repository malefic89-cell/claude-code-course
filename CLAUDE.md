# CLAUDE.md — Обучающее приложение «Claude Code Course»

## О проекте

Веб-приложение для обучения работе в Claude Code через практические задачи.
Формат вдохновлён self-paced курсами: модули → задачи → чек-листы → трекер прогресса.
Принцип: **80% практики** — каждая задача выполняется пользователем в реальном терминале с Claude Code, приложение даёт инструкцию и проверяет результат.

**Аудитория (по приоритету):**
1. Сотрудники IT-лаборатории (MVP)
2. Ученики школы
3. Внешние пользователи (после пилота)

**Язык интерфейса:** русский (архитектура должна допускать i18n в будущем — все строки UI выносить в словари, не хардкодить).

## Технический стек

- **Next.js 14+ (App Router), TypeScript, React**
- **Tailwind CSS** для стилей
- **Хранение прогресса:** localStorage в MVP (обёрнуто в отдельный модуль `lib/progress.ts`, чтобы позже заменить на серверную БД без переписывания компонентов)
- **Контент курса:** Markdown/JSON-файлы в `/content` — редактируются без деплоя кода
- Без авторизации в MVP. Без внешних БД в MVP.

## Структура проекта

```
/app                — маршруты Next.js (App Router)
  /page.tsx         — главная: каталог модулей + общий прогресс
  /module/[id]      — страница модуля со списком задач
  /task/[id]        — карточка задачи
/components         — UI-компоненты (ModuleCard, TaskChecklist, ProgressBar…)
/content
  /modules          — module-01.json, module-02.json… (метаданные модулей)
  /tasks            — task-01-01.md… (тексты задач в Markdown с frontmatter)
/lib
  /content.ts       — загрузка и парсинг контента
  /progress.ts      — API прогресса (единственная точка работы с хранилищем)
/public             — статика, иконки модулей
```

## Формат контента

Каждая задача — Markdown-файл с frontmatter:

```yaml
---
id: "01-03"
module: "01"
title: "Первый запуск Claude Code"
difficulty: easy | medium | hard
estimated_minutes: 10
---
## Цель
## Инструкция (пошагово)
## Критерий выполнения
«Задача выполнена, если…» — конкретный проверяемый результат.
## Подсказки (опционально, скрыты по умолчанию)
```

Модуль (JSON): id, title, description, icon, порядок задач.

## Программа курса

MVP — модули 1–3. Остальные добавляются позже, архитектура должна их поддерживать сразу.

1. **Основы CLI** — установка, первый запуск, базовые команды, режимы (MVP)
2. **CLAUDE.md** — контекст проекта, инструкции, память (MVP)
3. **Plan mode и итерации** — планирование, ревью, циклы (MVP)
4. MCP-серверы
5. Субагенты и параллельная работа
6. Git-интеграция

## Функциональность MVP

- Каталог модулей с прогрессом по каждому
- Страница задачи: цель, инструкция, чек-лист «критерий выполнения», кнопка «Выполнено»
- Общий трекер прогресса (X из Y задач, % по модулю)
- Раскрываемые подсказки в задачах
- Адаптивная вёрстка (сотрудники и ученики могут открывать с ноутбука и телефона)

**Не делаем в MVP:** авторизацию, серверное хранение, AI-проверку ответов, геймификацию (стрики/бейджи), английскую локализацию. Но код не должен блокировать их добавление.

## Правила разработки

- Работаем итеративно: сначала план (plan mode), затем реализация небольшими шагами с проверкой
- Каждая фича — отдельный коммит с осмысленным сообщением на английском (`feat:`, `fix:`, `content:`)
- Контентные правки (тексты задач) не должны требовать изменений кода
- Компоненты — маленькие и типизированные; никакого `any`
- Перед добавлением библиотеки — спросить, нельзя ли обойтись без неё
- Не изобретать содержание задач курса самостоятельно: тексты задач пишет/утверждает автор курса, Claude помогает со структурой и черновиками по запросу

## Команды

```bash
npm run dev      # локальная разработка
npm run build    # проверка сборки перед коммитом
npm run lint     # линтер — обязателен перед коммитом
```

## Дорожная карта (контекст для решений)

- **Этап 1:** контент модулей 1–3 (задачи в /content)
- **Этап 2–3:** каркас приложения и MVP
- **Этап 4:** пилот на 2–3 пользователях, сбор точек застревания
- **Этап 5:** модули 4–6, геймификация, серверный прогресс, AI-проверка через Anthropic API, внешние пользователи

## Риски (учитывать при проектировании)

- Claude Code быстро обновляется → контент версионировать, в frontmatter задач хранить `verified_date`, ревизия раз в квартал
- Разный уровень аудитории (сотрудники vs школьники) → поле difficulty и подсказки обязательны с первой версии
